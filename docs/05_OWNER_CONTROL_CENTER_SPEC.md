# Founder Control Center

## Goal
One owner-focused interface for operations + CRM + exceptions. The founder should not manually process routine orders.

## Main dashboard
Top controls:
- Store accepting ON/OFF
- Delivery ON/OFF
- Pickup ON/OFF
- In-store ON/OFF
- Acceptance mode AUTO/HYBRID/MANUAL

KPIs:
- Revenue
- Paid Orders
- AOV
- Repeat %
- First→Second Conversion

Live:
- Awaiting Review
- Preparing
- Ready
- Delivery Active
- Pickup Active

Kitchen Health:
- Load %
- Next capacity
- KDS online/offline
- delayed orders

Needs Your Attention:
- only exceptions

CRM:
- new
- returning
- reactivated
- second-order pending

Loyalty:
- Member / Silver / Gold / Platinum counts
- points issued
- redeemed
- pending

## Paid order review
Card:
- order
- paid amount
- fulfillment
- customer
- tier
- issue
- system recommendation
- Accept Anyway
- Reject & Refund

## Accept dialog
Explain:
- expected load
- promise window
- consequence

Accept:
- marks accepted
- schedules
- sends KDS
- updates customer

## Reject dialog
Explain:
- money already received
- reason
- no KDS entry
- refund starts
- customer notified
- CRM updated

## Availability
Owner can:
- disable whole product
- disable by fulfillment
- disable variant
- disable modifier
- see chef temporary override

Owner override is highest authority.

## Customer Search
Search by:
- name
- masked phone
- order ID

Customer 360 drawer:
- tier
- available/pending/expiring points
- next tier
- rolling spend/orders
- lifetime orders/LTV/AOV
- source split
- favourites
- tags
- timeline

Owner cannot manually set tier.
